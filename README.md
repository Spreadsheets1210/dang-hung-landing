# Đăng Hưng Technology
Website hồ sơ năng lực và danh mục sản phẩm dựa trên HoSoNangLuc_Platinum_v3.pdf. Trang chủ ưu tiên doanh nghiệp và công trình. Thanh điều hướng có Giới thiệu, Công trình, Sản phẩm và Liên hệ.

## Nội dung
- Thư ngỏ, pháp nhân, tầm nhìn, sứ mệnh, 5 giá trị, quan hệ thương hiệu.
- 10 nhóm giải pháp, 6 bước triển khai, cam kết và 6 lý do lựa chọn.
- 19 dự án có trang chi tiết riêng, toàn bộ hạng mục và 90 ảnh công trình.
- 36 sản phẩm của Roger Technology, Homegy, Philips, Fasla và Bose; bộ lọc, tìm kiếm, trang từng hãng.
- PDF gốc 35 trang ở public/docs/.

## Chạy và kiểm tra
Yêu cầu Node.js 22.12+ hoặc 24+.
- npm install
- npm run dev
- npm test
- npm run build
- npm run preview -- --port 4173


Bản build tĩnh ở dist/. 

## Các tệp chính
- src/profile-pages.tsx: trang chủ, giới thiệu, danh sách và chi tiết công trình.
- src/profile-data.ts: nội dung doanh nghiệp.
- src/project-data.ts: 19 dự án.
- src/catalog-data.ts: sản phẩm và thương hiệu.
- src/main.tsx: điều hướng, sản phẩm và tìm kiếm.
- src/styles.css: giao diện.
- public/assets/projects/provenance.json: nguồn 90 ảnh công trình.
- public/assets/catalog/provenance.json: nguồn ảnh sản phẩm.

Hồ sơ ghi tổng hợp 86 hạng mục; cộng các dòng tại 19 trang dự án được 93. Website giữ nguyên từng hạng mục và phân biệt số tổng hợp theo nguồn. Các ảnh đại diện dòng Roger/Philips có chú thích. Thông tin pháp nhân, địa chỉ, số liệu và vai trò phân phối được ghi theo hồ sơ 2026.
